# Extra Task 1e — UML as a General Modeling Language

## Topic

The topic of this extra task is:

```text
Submitting a Laboratory Work Before Deadline
```

This is not a software system design model. Instead, UML is used as a general modeling language to describe a real-life student workflow.

## Purpose

The purpose of this model is to show that UML can describe not only software systems, but also everyday processes, decisions, states, and interactions.

## Explanation

The modeled situation describes how a student completes and submits a laboratory work.

The process includes reading requirements, planning, implementation, documentation, creating UML diagrams, committing changes, pushing to GitHub, submitting the repository link, and receiving feedback.

The model demonstrates that UML can be used to describe:

- participants and their goals;
- workflow steps;
- state changes;
- interactions between people and tools.

## Conclusion

This example shows that UML can be useful outside of software architecture. It can also describe real-world processes in a structured and visual way.
